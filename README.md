# Project1_SMS
A simple Python command-line application to manage student records — built as a beginner-friendly mini project to practice core programming concepts like functions, loops, conditionals, and data structures.

ABOUT:
This project allows users to perform basic CRUD (Create, Read, Update, Delete) operations on student data through an easy-to-use console menu. It's designed for beginners learning Python and is a great starting point for understanding how simple data management systems work.

FEATURES:
Add Student — Add a new student with name, age, course, and marks
View All Students — Display all student records in a neat table
Search Student — Find a student by their ID
Update Student — Edit an existing student's details
Delete Student — Remove a student record
Exit — Close the application

NOTE: 
1.Built With Python 3 — No external libraries or installations required
2.This version stores data in memory using a Python list — records will reset each time the program is closed.
3.A future improvement could include saving data permanently using a file (.txt/.csv) or a database (SQLite).
